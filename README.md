# Segundo Parcial — Sistema de Citas Médicas

Proyecto de Análisis de Sistemas II.

Incluye:
- MySQL ejecutándose en Docker.
- API REST para gestión de citas médicas.
- Validación de conflictos de horario en servidor.
- Gestión de estados de citas.
- Interfaz interactiva con FullCalendar.

## Flujo Git

Cada funcionalidad se desarrolla en una rama feature y se integra mediante Pull Request hacia main.
